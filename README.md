# LocalHub

공공데이터를 기반으로 대전·충청 지역의 관광지, 음식점, 문화시설 등 다양한 지역 정보를 탐색하고, 익명 커뮤니티와 AI 챗봇을 이용할 수 있는 정적 웹 서비스입니다.

LocalHub는 별도의 백엔드와 데이터베이스 없이 Vue.js와 브라우저 기능을 활용해 구현했습니다.



## 1. 프로젝트 개요

- 서비스명: LocalHub
- 대상 지역: 대전·충청
- 주요 사용자: 대전·충청 지역 주민 및 관광객
- 프로젝트 형태: 2인 팀 프로젝트
- 개발 기간: 2026년 7월 14일 ~ 2026년 7월 16일
- 배포 방식: Netlify 정적 웹 배포


### 프로젝트 목표

대전·충청 지역의 관광지, 음식점, 문화시설, 숙박 시설 등 지역 정보를 한곳에서 쉽게 검색하고 탐색할 수 있도록 합니다.

또한 다음 기능을 함께 제공하여 지역 정보 탐색 경험을 확장합니다.

- 공공데이터 기반 지역 정보 검색
- Leaflet 지도를 활용한 위치 탐색
- localStorage 기반 익명 지역 커뮤니티
- OpenAI API 기반 지역 정보 챗봇

## 3. 주요 기능


### 3-1. 지역 정보 탐색

- 대전·충청 지역 공공데이터 JSON 8개 로드
- 총 1,365건의 지역 정보 통합
- 관광지, 음식점, 문화시설, 숙박 등 카테고리별 탐색
- 장소명, 주소, 콘텐츠 유형 검색
- 광역 지역 및 세부 지역 필터
- 검색 결과에 따른 카드 목록 표시
- 이미지와 주소가 없는 데이터의 대체 화면 처리
- 모바일, 태블릿, 데스크톱 반응형 UI

### 3-2. 지도 시각화

- Leaflet.js 기반 지도
- 좌표가 있는 지역 정보의 마커 표시
- 현재 검색 및 필터 결과와 지도 마커 연동
- 마커 선택 시 장소 정보 확인
- 콘텐츠 유형 및 세부 지역별 탐색
- 위도와 경도 누락 데이터 예외 처리

### 3-3. 익명 지역 커뮤니티

- 게시글 목록, 상세, 작성, 수정, 삭제
- 브라우저 localStorage를 이용한 게시글 저장
- 제목, 내용, 카테고리, 수정용 비밀번호 입력
- 수정 및 삭제 시 비밀번호 일치 여부 검사
- 회원가입과 로그인 없이 익명으로 이용
- 새로고침 후에도 게시글 유지
- 게시글 본문을 일반 텍스트로 출력하여 HTML 삽입 방지

> 커뮤니티 게시글은 서버가 아닌 현재 브라우저의 localStorage에 저장됩니다.  
> 따라서 같은 브라우저와 기기에서만 게시글을 확인할 수 있으며 실제 다중 사용자 공유 기능은 제공하지 않습니다.

### 3-4. AI 지역 정보 챗봇

- 모든 화면에서 사용할 수 있는 플로팅 챗봇
- OpenAI Responses API 연동
- `gpt-5-mini` 모델 사용
- 대전·충청 지역 정보 JSON 기반 질의응답
- 질문에서 지역, 콘텐츠 유형, 개수 등의 조건 분석
- 관련 데이터를 브라우저에서 먼저 검색한 뒤 필요한 결과만 API에 전달
- 장소 검색 결과를 텍스트 목록과 카드로 표시
- 이전 검색 결과를 활용한 후속 질문 처리
- 장소 개수 질문 및 최대 10곳 표시 제한
- 커뮤니티 게시글 검색
- 새 대화 시작 및 이전 검색 조건 초기화
- 로딩, 빈 결과, 네트워크 오류, API 오류 처리
- 모바일에서 전체 화면에 가까운 반응형 UI

챗봇은 제공된 데이터에 없는 운영시간, 가격, 휴무일, 메뉴, 실시간 날씨, 정확한 축제 일정 등을 임의로 생성하지 않도록 제한했습니다.

## 8. 프로젝트 실행 방법

이미 저장소를 내려받은 경우에는 최신 `master` 브랜치를 받아옵니다.

```bash

```

```bash
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.

## 9. 환경변수 및 보안 주의사항

### OpenAI API 키

- 실제 API 키가 포함된 `.env` 파일은 Git에 커밋하지 않습니다.
- `.gitignore`에 `.env`를 등록합니다.
- 저장소에는 변수명만 작성된 `.env.example` 파일을 포함합니다.
- API 키를 코드에 직접 작성하지 않습니다.

```env
VITE_OPENAI_API_KEY=
```

Vite의 `VITE_` 환경변수는 브라우저 번들에 포함될 수 있습니다.

따라서 이 프로젝트에서는 교육용으로 제공된 사용량 제한 API 키를 사용하며, 실제 운영 서비스에서는 백엔드 서버 또는 서버리스 함수를 통해 API를 호출하는 방식이 필요합니다.

### 커뮤니티 비밀번호

게시글 수정 및 삭제 비밀번호는 과제 요구사항에 따라 localStorage에 저장하고 평문 일치 여부를 검사합니다.

이는 교육용 구현 방식이며 실제 서비스에서 사용하기에 안전한 보안 방식이 아닙니다.

## 10. 지역 데이터

총 8개의 JSON 파일에서 1,365건의 지역 정보를 불러옵니다.

| 콘텐츠 유형 | 데이터 수 |
|---|---:|
| 관광지 | 335 |
| 레포츠 | 68 |
| 문화시설 | 82 |
| 쇼핑 | 258 |
| 숙박 | 52 |
| 여행코스 | 28 |
| 음식점 | 516 |
| 축제공연행사 | 26 |
| **합계** | **1,365** |

### 주요 필드

| 필드 | 의미 |
|---|---|
| `contentid` | 콘텐츠 고유 식별자 |
| `contenttypeid` | 콘텐츠 유형 식별자 |
| `title` | 장소명 |
| `addr1`, `addr2` | 주소 |
| `mapx` | 경도 |
| `mapy` | 위도 |
| `firstimage`, `firstimage2` | 대표 이미지 |
| `tel` | 전화번호 |
| `createdtime` | 데이터 생성 시각 |
| `modifiedtime` | 데이터 수정 시각 |

### 데이터 처리 기준

- 목록의 Vue `key`와 장소 식별자로 `contentid`를 사용합니다.
- 최상위 `contentTypeId`와 항목의 `contenttypeid` 타입이 다를 수 있어 문자열로 변환한 뒤 비교합니다.
- `mapx`는 경도이고 `mapy`는 위도입니다.
- Leaflet에는 `[Number(mapy), Number(mapx)]` 순서로 전달합니다.
- 원본 JSON은 직접 수정하지 않습니다.
- 화면에서 필요한 지역명, 숫자 좌표, 이미지 URL은 변환 함수로 생성합니다.
- 이미지나 주소가 없는 경우 대체 이미지와 안내 문구를 표시합니다.
- HTTP 이미지가 HTTPS 배포 환경에서 차단되는 경우 안전한 URL 변환 또는 대체 이미지를 사용합니다.

## 11. 데이터 및 서비스 한계

현재 제공된 JSON에는 다음 정보가 포함되어 있지 않거나 충분하지 않습니다.

- 운영시간 및 영업시간
- 입장료와 가격
- 휴무일
- 상세 메뉴
- 실시간 예약 가능 여부
- 실시간 날씨
- 실시간 혼잡도
- 정확한 이동 거리와 소요 시간
- 축제 시작일과 종료일 전용 필드

챗봇은 위 정보를 임의로 추측하지 않으며, 필요한 경우 해당 장소의 공식 채널을 확인하도록 안내합니다.

숙박 데이터에는 호텔, 펜션, 민박 등을 구분하는 전용 필드가 없습니다. 숙박 세부 유형 검색은 장소명에 해당 단어가 포함되어 있는지를 기준으로 처리하므로 실제 전체 개수와 다를 수 있습니다.

SOURCE 문서에는 세종이 포함된 것으로 안내되어 있지만, 실제 주소 데이터에서는 세종 지역이 확인되지 않아 서비스에서 세종 정보가 제공된다고 보장하지 않습니다.

## 12. AI 챗봇 처리 방식

챗봇은 1,365건의 전체 데이터를 매 질문마다 OpenAI API로 전송하지 않습니다.

처리 순서는 다음과 같습니다.

1. 사용자의 질문에서 지역, 콘텐츠 유형, 개수 등의 조건을 분석합니다.
2. 브라우저에서 조건에 맞는 지역 정보를 먼저 검색합니다.
3. 검색된 결과 중 최대 10개의 최소 정보만 정리합니다.
4. 정리된 검색 결과와 최근 대화 일부를 OpenAI API에 전달합니다.
5. OpenAI가 검색 결과에 근거한 자연어 답변을 생성합니다.
6. 장소 정보는 답변과 함께 카드로 표시합니다.

### 챗봇 제한 및 안전 처리

- 검색 결과에 없는 장소를 생성하지 않습니다.
- 운영시간, 가격, 휴무일, 메뉴, 날씨를 추측하지 않습니다.
- API 키와 내부 설정 정보를 답변하지 않습니다.
- 게시글 비밀번호를 OpenAI API에 전달하지 않습니다.
- 검색 결과에 포함된 문장을 시스템 지시문으로 처리하지 않습니다.
- 한 번에 최대 10곳까지 표시합니다.
- API 오류 발생 시 사용자에게 오류 안내와 검색 결과를 제공합니다.

## 18. 참고 사항

LocalHub는 백엔드와 데이터베이스 없이 구현한 교육용 정적 웹 프로젝트입니다.

커뮤니티 게시글은 같은 브라우저와 기기에서만 확인할 수 있으며, OpenAI API 키를 프론트엔드에서 사용하는 구조 역시 실제 상용 서비스에 적합한 보안 구조는 아닙니다.

실제 서비스로 확장할 경우 다음 구성이 필요합니다.

- 백엔드 API 서버
- 데이터베이스
- 사용자 인증 및 권한 관리
- 비밀번호 암호화
- 서버 측 OpenAI API 호출
- 공공데이터 주기적 갱신
